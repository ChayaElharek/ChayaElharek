## About me

I work with **Backend, DevOps and Infrastructure**, building and operating systems that run in production for a SaaS platform.

My work sits at the intersection of software development and infrastructure: application code, traffic routing at the edge, containers, deployment, monitoring and production troubleshooting. I enjoy understanding systems end-to-end, from the request hitting the server to the database and back.

Day to day, this includes:

- Developing and maintaining high-traffic request handling with **OpenResty / Lua** and **Redis**
- Backend services and integrations in **Node.js** and **PHP**
- Frontend work with **React**
- Running containerized workloads with **Docker** on Linux servers
- CI/CD, deployment automation and environment configuration
- Investigating and resolving production incidents across application, network and infrastructure layers

> Most of my work is in private repositories under employer and client confidentiality, so it is not published here.
